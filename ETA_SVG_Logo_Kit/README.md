# ETA SVG logo kit

Files:
- `eta-logo-light.svg` and `eta-logo-dark.svg`: full stacked wordmark for the respective themes.
- `eta-horizontal-light.svg` and `eta-horizontal-dark.svg`: website navigation.
- `eta-symbol.svg`: icon-only, suitable for favicon and compact UI.
- `eta-loader.svg`: animated vector loading mark, reduced-motion aware.

These are genuine SVG geometric vector reconstructions of the approved logo concept, not PNG images embedded in SVG. The geometry and typography are an approximation of the supplied raster masters, **not a pixel-identical trace**. Full-logo text uses system sans-serif SVG text and may render differently depending on installed fonts. For trademark/print masters, convert approved lettering to outlined paths in a vector editor.

Example:
`<link rel="icon" type="image/svg+xml" href="/eta-symbol.svg">`

Light and dark logos have transparent backgrounds. Keep the dark version on a dark surface.
